# proj1

A simple Java Maven project demonstrating employee salary and tax calculation using polymorphism.

## Overview

This project includes:
- `com.day2.App` as the application entry point
- `Taxable` interface for tax calculation
- `Employee`, `FullTimeEmployee`, and `PartTimeEmployee` model classes
- A sample runtime that prints salary and tax for multiple employees

## Requirements

- Java 17
- Maven

## Build

```bash
mvn clean compile
```

## Run

```bash
mvn exec:java
```

## Test

```bash
mvn test
```

## Project Structure

- `src/main/java` - application source code
- `src/test/java` - unit tests
- `pom.xml` - Maven project file

## Notes

This project is part of Spring Boot learning exercises, but it currently contains plain Java code and Maven setup.
